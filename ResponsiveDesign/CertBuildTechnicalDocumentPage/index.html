Introduction

Python is a popular programming language.

It is known for its simple syntax.

print("Hello World")
  • Easy to learn
  • Readable syntax
Variables

Variables store data values.

You can assign numbers or text to variables.

x = 10 name = "Luke"
  • Strings
  • Integers
Functions

Functions allow reusable code.

They help organize programs.

def greet(): print("Hi")
  • Reusable
Loops

Loops repeat code multiple times.

Python supports for and while loops.

for i in range(5): print(i)
  • For loops
  • While loops
Lists

Lists store multiple values.

They are ordered collections.

numbers = [1, 2, 3]

You can access items using indexes.

Lists are mutable.

  • Ordered
  • Mutable
